## Architectural Decisions to Lock

### 1. Zero-Mock Integration Test Execution Boundary
- **No Mocking of DOM, Calculators, or Math:** Integration testing must run directly against the live DOM generated by `index.html` or inside a headless browser environment (e.g., Playwright / Puppeteer / jsdom with full script evaluation).
- **Prohibition of Synthetic Stubs:** No simulated math engines, no mock slider event objects, and no synthesized JSON response objects are permitted. Every test input must be injected via standard DOM element value assignment (`HTMLInputElement.value = ...`) and standard browser dispatch events (`new Event('input')`, `new Event('wheel')`, `new PointerEvent('pointerdown')`).
- **Strict Boundary (`INV-BOUNDARY-01`):** Zero test execution code, test fixtures, parsers, or dummy payloads are written during this planning session.
